## Simples, rápida e desenvolvida em GO

Uma API REST para transformar arquivos XML de Notas Fiscais
Eletrônicas (NF-e) em documentos DANFE no formato PDF.

## Como funciona?

1. Obtenha um token de acesso.
2. Envie um arquivo XML de NF-e para a API ([consulte a documentação](/godanfe-docs/api/)).
3. Receba o DANFE gerado em formato PDF.
